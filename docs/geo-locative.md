# Фразы местоположения геообъектов

`geo_units.name_locative` — необязательная строка до 255 символов с готовой
фразой и предлогом: `в Санкт-Петербурге`, `во Всеволожском районе`,
`на территории Залитских островов`.

Поле доступно при создании и редактировании геообъекта в админке. Фраза используется в автоматическом Title карточки организации.
Среди назначенных территорий выбирается одна с минимальным OSM-уровнем,
при равных уровнях используется меньший ID. Если фраза отсутствует,
выводится «регион: {название}».

## Первоначальное заполнение

Обычный `php artisan migrate --force` добавляет колонку и заполняет её по
словарю `database/data/geo_unit_locatives.json`. Словарь содержит 999 уникальных
названий для 1008 записей локальной базы на 25.11.2026, включая 11 регионов.
Сопоставление идёт по точному названию, независимо от ID в окружении.
Читаются только ID и название, без геометрии; обработка идёт порциями по 100.

Непустые значения и даже явно сохранённая пустая строка не перезаписываются.
Неизвестные названия остаются с NULL; новые объекты можно заполнить вручную.
Изменение основного названия не пересчитывает введённую фразу автоматически.

В административных названиях вида `городской округ Великий Новгород`
используется форма `в городском округе «Великий Новгород»`: склоняется родовое
обозначение, собственное название выделено кавычками и сохранено. В остальных
типах склоняются согласованные части: `Бронницкое сельское поселение` →
`в Бронницком сельском поселении`. У топонимов на -ово/-ино используется
допустимый несклоняемый вариант, например `в Комарово`.

Общие правила склонения географических названий:
[Грамота.ру](https://gramota.ru/biblioteka/spravochniki/pismovnik/kak-sklonyat-geograficheskie-nazvaniya).

При откате миграции заполнения значения сохраняются, поскольку они могли быть
отредактированы. Откат миграции колонки удаляет колонку вместе с её данными.
